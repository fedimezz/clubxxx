# 2026-11-23 — Complete UX/UI upgrade (owner dashboard, 9 themes, pro planning, reservation cutoff)

Additive only: no feature removed, no API route removed or renamed, no auth change, strict club isolation kept
(the club always comes from the authenticated account — never from the request).

## What was delivered
1. **Owner/admin dashboard** (`/admin`) — real data from `GET /api/admin/dashboard?range=7d|30d|90d|12m`:
   active members, today's reservations, pending subscriptions, monthly revenue (TND, OWNER only), new members this
   month, expired memberships; growth / revenue / reservations / subscription-performance charts; quick actions;
   recent activity; club health (website, mobile, payments, email, domain); skeletons, empty states, toasts,
   tooltips, responsive layout, collapsible sidebar, header (welcome, club, global search, notifications, profile, date).
2. **9 themes** — Musculation, CrossFit, Boxing & MMA, Yoga & Bien-être, Fitness Moderne, Neon Performance,
   Luxury Club (new "private" layout), Urban Street, Minimal Elite: distinct nav, hero, pricing presentation,
   typography, backgrounds and image treatment (`app/themes.css`, `app/themes-identity.css`, `PricingVariants`,
   `Navbar`, `ThemedHome`). All unlocked. "Mon modèle 3D" remains a separate locked premium feature.
   Theme picker: large previews, **full-site preview (iframe) before applying**, desktop/mobile switch, search +
   category filters, active theme badge, Apply button. Club content/logo/name/phone/settings are untouched on switch.
3. **Pro planning calendar** (admin Planning, default view; the classic "Semaines" list is kept): day / week / month,
   prev / next / Today / date picker, coach + activity filters, colour-coded sessions (colour is never the only cue),
   capacity bars, side panel (details, closing time, edit/delete), double-booking warnings (same coach or room) both
   in the calendar and in the session form, responsive. View + date live in the URL (`?view=&date=`) and the last view
   is remembered.
4. **Week-navigation bug fixed** (member schedule). Root causes: month Prev/Next used `Date#setMonth` (31 Mar − 1 month =
   3 Mar → button looked dead); the whole page was replaced by a spinner on every navigation (buttons unmounted);
   out-of-order responses could show an older week under a newer label. Now: pure calendar-date arithmetic
   (`lib/calendar-nav.ts`), functional state updates, latest-request-wins fetching, toolbar never unmounted/disabled.
5. **20-minute reservation cutoff** — enforced server-side inside the booking transaction
   (`POST /api/dashboard/schedule/book` → 403 `RESERVATION_CLOSED`), club timezone + DST aware
   (`lib/timezone.ts`, `lib/reservation-cutoff.ts`), message "Les réservations ferment 20 minutes avant le début de la
   séance.", existing reservations are never cancelled. UI: button disabled, "Réservations jusqu'à HH:mm", clock
   corrected with the server time. The same endpoint serves web and mobile.
6. **Member experience** — schedule (day/week/month/"À venir" agenda), dashboard quick actions, membership expiry alert, skeletons.
7. **Coach dashboard** — "Aujourd'hui" first (live / done badges), next-session banner, other days, roster + attendance
   with present counts. No financial data anywhere in the coach routes.
8. **Design system** — `components/ui/{Skeleton,EmptyState,Tooltip,ConfirmDialog,Toast}`, shared calendar kit in
   `components/schedule/`, admin tokens in `app/admin/admin-ui.css`.

## Database

(`gym_settings.timezone TEXT DEFAULT 'Africa/Tunis'`, `gym_settings.reservationCutoffMinutes INT DEFAULT 20`).
No data rewritten, no new model. Run `npx prisma migrate deploy` then `npx prisma generate`.

## API changes (all additive)
- NEW `GET /api/admin/dashboard` (ADMIN/OWNER; revenue/plan/payments only for OWNER)
- NEW `GET /api/admin/sessions/[id]` (roster, club-scoped)
- `GET /api/dashboard/schedule`: + per-session `startsAt`, `reservationClosesAt`, `reservationOpen`, `reservationStatus`, + `reservationPolicy`
- `GET /api/admin/schedule`: + `timeZone`, `reservationCutoffMinutes`
- `GET /api/dashboard/coach/sessions`: + `timeZone`, per-session `weekStart`
- `POST /api/dashboard/schedule/book`: 403 `RESERVATION_CLOSED` when inside the cutoff
