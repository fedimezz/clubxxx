# ClubX — 2026-10-30: dedicated 14-day TRIAL plan, image fix, Prisma race fix

## 1. Free trial = its own limited plan (not "pick a plan, use it free")
- New `SaasPlanTier.TRIAL` ("Essai gratuit", price 0, never public, never purchasable).
  Defaults: 30 members, 2 coaches, 2 admin seats (owner + 1), 100 bookings/month, no custom domain /
  analytics / API / white-label / custom 3D model. Editable by SUPER_ADMIN in /platform/plans (name + limits only).
- Signup (`create-club`, trial path): `planId` is no longer accepted/needed; the club is put on the TRIAL plan
  (`lib/trial-plan.ts` → `ensureTrialPlan()`, creates the row on first use, never overwrites edits).
- Onboarding step 5: "Essai gratuit" shows ONE trial card with its limits (no plan list, no billing toggle).
  Paid / contact modes still list the paid plans.
- The TRIAL plan can never be bought: excluded from `PUBLIC_PLAN_WHERE` and `findPlanForClub`
  (checkout, reactivation, manual payment). After the 14 days the existing flow applies: club suspended →
  /reactivate → owner picks a REAL plan → `planId` is switched on payment.
- Platform plans PATCH: TRIAL price/public/active changes are ignored; other plans still need price > 0.

## 2. Images ("upstream image response timed out")
- `lib/cloudinary-loader.ts` + `images.loader: "custom"` in next.config.ts: Cloudinary/Unsplash resize + AVIF/WebP
  on their CDN, the browser loads directly from the CDN. The Next server no longer proxies/resizes every image.
  CSP `img-src` already allowed both hosts. `safeImageUrl` (host allow-list) unchanged.
- Uploads to Cloudinary are capped at 2000px / `q_auto:good` (no more multi-MB PNGs).

## 3. Prisma P2002 on `userPreferences`
- `getOrCreatePreferences` is now an atomic `upsert` (parallel GETs no longer crash).

## 4. Other
- `compress: true` in next.config.ts. New test `lib/__tests__/cloudinary-loader.test.ts`; updated
  `onboarding-e2e.test.ts` and `saas-plan-visibility.test.ts` for the TRIAL plan.

## RUN THIS (in order, on your machine)
```
npx prisma migrate deploy        # adds the TRIAL enum value (migration 20261030000000_trial_plan_tier)
npx prisma generate
npm run build && npm start
```
Optional: `npx prisma db seed` also creates the TRIAL plan (the app creates it by itself at first signup anyway).
Existing clubs already in TRIAL keep the plan they were created on; only NEW trial signups use the TRIAL plan.

## Email 403 (Resend)
Resend only sends to your own address until you verify a domain. No code change needed: set SMTP in `.env`
(already supported, takes priority over Resend), e.g. Gmail app password:
`SMTP_HOST=smtp.gmail.com  SMTP_PORT=465  SMTP_USER=you@gmail.com  SMTP_PASS=<app password>  SMTP_FROM=you@gmail.com`
